# AI-Code-Review-Sandbox
A sandbox repository built solely for the purpose of testing the AI Code Review Assistant. 

The repository content contains a backend folder (utilizing FastAPI), and a frontend folder (utilizing Vue.js), depicting a sample CRMS system.

# How To Run Backend:
1. CD into backend folder
2. Type 'python -m venv venv' in terminal (if venv does not exist)
3. Activate in terminal using 'venv\Scripts\activate' command
4. Run command 'uvicorn main:app --reload' to run backend

# How To Run Frontend:
1. CD into frontend folder
2. Run 'npm i' command in terminal
3. Run 'npm run dev' for localhost viewing
